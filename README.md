# (unnamed word game)

An ad-free, open-source, asynchronous crossword-tile word game for playing with friends.
Mobile-first web app, installable to your phone's home screen.

- Sign in with your email and a one-time code — no passwords.
- Start a game with anyone whose email you know; invite them if they're new.
- Self-host on Cloudflare Workers or with Docker.

**Status:** specification phase. See [`docs/spec/`](docs/spec/README.md).

The product name is deliberately not chosen yet; deployments set it via the `APP_NAME` variable.
